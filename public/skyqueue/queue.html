How Our Reservation Queue Works

Micro project: Airline Reservation System Using Queue in C.

What is a queue?

A queue is a line, like passengers waiting at a check-in counter. New people join at the rear, and the person at the front is served first. This rule is called FIFO — First In, First Out.

How SkyQueue uses it

  • Each flight has 5 confirmed seats.
  • If a seat is free, the passenger is confirmed and given the first free seat.
  • If all 5 seats are full, the passenger is enqueued (added to the rear of the waiting list).
  • When a confirmed passenger cancels, the passenger at the front of the waiting list is dequeued and gets that seat.

Linked list representation

Each waiting passenger is a node holding a ticket ID, a name and a next pointer. We keep two pointers: front and rear.

front → 106 Karan→ 107 Neha→ 108 Arjun→ NULL ← rear

Time complexity

OperationComplexityWhy
Enqueue (join waiting list)O(1)Add directly after the rear pointer
Dequeue (promote first waiting)O(1)Remove directly at the front pointer
Book a ticketO(n)Search the n = 5 seats for a free one, then O(1) enqueue if full
Cancel a ticketO(n + w)Search seats, else search the w waiting nodes
DisplayO(n + w)Visit every seat and every waiting node

Space: O(n + w) — one record per passenger.

C program vs browser simulation

airline.c is the original program, run in a terminal. Browsers cannot run C, so script.js re-implements the same logic (same 5 seats, same ticket numbers starting at 101, same FIFO promotion) in JavaScript. The website does not call the C program.
